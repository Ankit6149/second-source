CODE: a method, not a metaphor

Every investigation follows the same four stages. Each stage hands validated, traceable data to the next — with durable run IDs, explicit statuses, and bounded execution.

C

Capture

Authorized targets are observed through approved adapters. Every action and response is hashed, timestamped, and stored with provenance.

Organize

Observations become evidence-linked hypotheses with competing explanations, citations, and confidence — never free-floating claims.

Verification is the product

A candidate never grades its own homework. Reference and candidate run separately against the same sealed suite — one the model never saw — and every mismatch is categorized, not averaged away.

Built for the cases docs can't answer

Wherever behavior is the contract and the source is unavailable, unverified, or untrusted.

Legacy systems nobody dares touch

Recover the real rules of aging internal tools from their behavior — then verify a safe replacement case by case instead of rewriting on folklore.

Vendor black boxes

Confirm that a third-party service still honors its contract after every update, with an independent behavioral fingerprint you own.

Migration safety nets

Rebuild a subsystem on a new stack and prove equivalence where it matters: observable behavior, error cases included.

Trust is a mechanism, not a mood

Authorization first

Runs start only after ownership acknowledgement, scope limits, and budget reservation. Destructive or externally visible actions need explicit approval.

Isolation by construction

Reference source, sealed cases, and credentials never enter model context. Candidates are declarative policies in a trusted interpreter — never generated code.

Uncertainty stays visible

Unknown model state reads “Can't verify,” never “Finished.” Costs carry uncertain remainders. Partial runs export partial reports.

Honest answers

Has an AI actually reconstructed software with this?

Partially. A genuine Meta run discovered real rules and chose a real experiment. But no model-generated candidate has yet been admitted and scored; both synthesis attempts failed beforehand. That gap is the current engineering focus, and this page will say when it closes.

Does it copy source code or break into software?

No. It only studies targets you own or are authorized to test, through observable behavior. The model never sees reference source, and candidates are newly written behavioral policies, not recovered code.

What does it cost to run?

Observation, evaluation, and the mock pipeline are free. Real model reasoning is capped by a per-run dollar limit you set — the recorded discovery run cost about $0.0135. Nothing billable ever runs without your explicit authorization.

Can I use it for my own system today?

You can run scoped CLI investigations, the evidence ledger, and the independent evaluator locally. The hosted backend, auth, and full operator workflow are in progress — see the status table above for exact states.
