06 / QUESTIONSTHE IMPORTANT DETAILS

Clarity, even
in the details.

Clear boundaries are as important as ambitious ideas.

Does it recover the original source code?+

No. It aims to create a new implementation that matches observed and tested behavior within a declared, authorized scope.

Can it reconstruct any website or application?+

No universal reconstruction is promised. Results depend on supported adapters, permitted observations, experiment budgets, and independently measurable behavior.

What makes it different from code generation?+

Second Source focuses on discovering behavioral rules through experiments and testing an independent candidate, rather than simply generating plausible code from a prompt.

Is the interactive demonstration real?+

The demonstration on this landing page is illustrative only. It makes no AI, backend, or evaluator calls and does not claim real verification results.
