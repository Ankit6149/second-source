What can people actually use?

The full architecture above is a product blueprint. These are the measured capabilities of the current system. The future nodes are deliberately separate, so a judge can explore the ambition without confusing it with features already shipped.

Working local reconstruction

Real probes and independently replayed evidence-compiled candidates on supported professional API targets: Vikunja 19/19, File Browser 7/7 and Gitea 6/6 public checks. Scores are bounded to the named test ladders, not full replicas.

Genuine Meta Muse reasoning

Server-side Meta Model API, real recorded Muse Spark experiments and a consent-gated local repair step. Muse identified Vikunja's default-project rule; the compiler subsequently derived it generically. Any new model edit must pass an independent public replay before being accepted.

Usable product surfaces

Public website, accounts, supported hosted investigations and report exports. The hosted executor is bounded NON_AI. The more capable supported-target reconstruction engine requires localhost and locally available references.
