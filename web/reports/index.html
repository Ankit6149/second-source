What the numbers mean

The compiler is the control, not the product

Deterministic evidence compilation transcribes exactly what was observed, so it scores high wherever behavior was publicly probed (19/19, 7/7, 6/6). That proves the observation and candidate machinery works. It does not prove intelligence — which is why Muse's contribution is measured separately, and why compiler scores are never relabeled as AI.

Muse alone is not enough — yet

Asked to reconstruct from specifications alone, Muse scored 14/25 on the sealed ledger and 3/7 on File Browser. Failures concentrate in exact response schemas (9) and error contracts (2): models approximate shapes; real systems are exact. This is a measured limitation, published with the failures kept.

Where Muse actually moved the score

On Vikunja the last divergence was per-user default projects. Muse, shown only public evidence, named them exactly: Inbox and My Open Tasks (1 call, $0.005464, receipt in repo). The candidate went 18/19 → 19/19, and the compiler now derives the same rule generically. Conversely, Muse whole-route rewrites regressed 11 → 2 and were rejected by the gate. Both directions are the evidence.

A number we had to earn twice

An apparent 17/19 regression turned out to be our own measurement bug: the ladder was replayed on an already-probed reference, creating a duplicate project. Baselines now always run on a fresh reference. Reporting this matters: a benchmark you cannot trust is worse than a lower score.

Method, in one paragraph

Probe the reference with public actions only → compile observations into a behavioral spec (observed facts immutable) → Muse reasons only about unknowns, proposing gated edits → execute the candidate with a generic interpreter → score public conformance on a fresh reference → freeze and score held-out suites evaluator-side only. Provider failures are recorded as unscored infrastructure events, never as zeros.

Limitations

Bounded, pinned subsystems — not arbitrary URLs (that is the stated end goal, not a current claim). Public conformance is not whole-product equivalence. The 14/25 attestation could not be provider-verified and is labeled recorded. Hosted execution is the bounded NON_AI worker; the full professional-target engine runs locally.
