01 / Protocol

Four steps. Independent verification.

A black-box approach does not mean guessing. Each stage keeps evidence, scope, and test ownership explicit.

01 — CAPTUREObserve real behavior

Within an authorized scope, record actual inputs, outputs, errors and state changes.

02 — ORGANIZESeparate facts from guesses

Track observed, inferred, conflicting and unknown rules independently.

03 — DISTILLConstruct a candidate

Generate a bounded specification. Keep model-authored and compiled facts labeled.

04 — EXECUTEChallenge the reconstruction

Run a separate evaluator; expose passed, failed and indeterminate outcomes.

REAL_MODELVikunja v2.4.0 · sealed six-case suite

Grounded versus active Meta reasoning

Two genuine Muse Spark 1.3 arms tested whether additional grounded observations and active probe selection improve reconstruction on professional task software.

2/6 · 1/6
Method and limitations

Grounded C reproduced 2/6 frozen workflows, and active D reproduced 1/6 after model-selected probes. The experiment demonstrates real model exploration, not a positive improvement. Original driver failure meant some ephemeral receipts were lost; the durable run record and packet digests remain in the research record.

REAL_MODELMuse-assisted hybrid · candidate versus compiler

Can a model improve a faithful compiler?

Proposed route-level changes were compared against an evidence-compiled candidate and evaluated independently.

6/6 + 6/6
Method and limitations

The raw model-assisted candidate tied the NON_AI evidence compiler on both frozen and extended suites. The public-conformance gate rejected the proposed edits. There is no measured improvement over the compiler, so the result is presented as a tie rather than a model win.
