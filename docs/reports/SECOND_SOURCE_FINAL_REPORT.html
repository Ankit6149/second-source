What it is. Second Source investigates authorized software, records what it actually does, compiles that evidence into an independent candidate, scores the candidate against the reference, and shows the code, the differences, and the proof. Every result is labeled REAL_MODEL (genuine Muse, recorded) or NON_AI (deterministic compiler) — never merged, never relabeled.

How it works

Instruction + authorized target → scope approval (digest-pinned) → observe (public probes) → compile evidence → candidate spec → verify (independent evaluator) → compare side-by-side → download code + report + proof bundle

Observed facts are protected: models must justify overriding evidence. Held-out cases are never in prompts. Provider failures are unscored, never shown as 0.

Failure analysis worth showing

Gitea 2/6: repo reads and issue operations fail on the candidate because compiled route templates keep the probed repo name literal instead of generalizing the segment; the auth boundary differs (404 vs 401) because error-only routes are not compiled. Both fixes are identified and measurable against this baseline.

Vikunja public ladder 11/19: divergences concentrate in read-after-share routes. The frozen and extended suites remain 6/6; the ladder is the stricter public check.

Why the hybrid claims a tie: every Muse edit was rejected by the public-conformance gate (singles 1–2/19 vs compiler 11/19). The raw merged candidate scored 6/6 + 6/6 once, after gating. The deployable candidate is the compiler — reported as such.

Limitations

  • Hosted investigations backend (Render blueprint) not yet activated; sign-in works on production, saved investigations need that deployment. The full flow runs locally today.
  • Model evidence is recorded and packet-authorized; no live unattributed model calls.
  • Gitea is a first-contact probe (2/6), not a completed benchmark.
  • Motion is a bounded spring/layout slice; no Canvas/WebGL/3D claim.

Artifacts

Per investigation: candidate specification (JSON), report.md / report.json, manifest.json with file SHA-256 digests, deterministic proof-bundle ZIP. In this repo: docs/reports/ (this report, per-software detail, results.json) and demos/software-tests/ (raw per-software videos and screenshots).
