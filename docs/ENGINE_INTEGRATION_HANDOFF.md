Backend owner surface for the frontend agent. No frontend files were changed.
All endpoints are owner-scoped (Bearer principal); another owner's resources
return 404. Everything below is `NON_AI` deterministic construction: no live
target probing, no model calls, $0 spend (guard-enforced).

## Event contract (v1, extended in place)

`GET /v1/orchestration/investigations/{id}/events?after=<event_id>&limit=100`

Events are durable, ordered by `event_id` (use it as the reconnect cursor),
and survive refresh. Fields: `event_id`, `investigation_id`, `job_id`,
`event_type`, `stage` (`capture|organize|distill|execute`), `revision`,
`created_at`, plus new `status`, `provenance`, `artifact_refs`, `detail`.

Status mapping: `stage_*`/`job_queued`/`job_claimed` = `RUNNING`;
`job_completed`/`delivery_ready` = `COMPLETED`; `job_failed` = `FAILED`;
`job_cancelled` = `CANCELLED`; reconciliation states = `CANNOT_VERIFY`
(reserved; emitted by worker paths when a lease outcome is uncertain).

Example (sanitized):

```json
{"schema_version":"1","event_id":9,"investigation_id":"inv-…","job_id":"job-…",
 "event_type":"stage_distill","stage":"distill","revision":6,
 "created_at":"2026-11-04T12:40:00+00:00","status":"RUNNING",
 "provenance":"NON_AI","artifact_refs":["art-0123456789abcdef"],"detail":"routes=2"}
```

## Candidate workspace endpoints

| Method & path | Response |
|---|---|
| `GET /v1/orchestration/investigations/{id}/workspace` | `WorkspaceV1`: latest `CandidateV1` (exact JSON spec the system built — it is a declarative spec, not a full website), `VerificationV1`, `ReportV1`, artifact list |
| `GET …/candidate` | `CandidateV1` only |
| `GET …/verification` | `VerificationV1` only |
| `GET …/export` | `ExportV1` with the proof-bundle `ArtifactRefV1` (`contains_sealed:false`) |
| `GET …/artifacts` | `ArtifactListItemV1[]` (id, kind, name, sha256, size, media type) |
| `GET …/artifacts/{art-[a-f0-9]{16}}/content` | Raw bytes with `Content-Disposition`; sha256 matches the list entry |

Artifact contents are generated by this backend from the authorized scope
only — no reference source, evaluator cases, or credentials are ever stored.

## Errors & recovery

- `409 CANDIDATE_NOT_READY` — workspace/export requested before `execute` completes.
- `404 NOT_FOUND` — unknown or other-owner investigation/artifact.
- `409 INVALID_STATE` / `LEASE_LOST` — execute/cancel/retry against a job in the wrong state; safe to refresh job state and retry deliberately (enqueue is idempotent, retry never duplicates a job).
- Cancel during execution stops before the next stage; the job finishes `cancelled` and no delivery event is emitted.
