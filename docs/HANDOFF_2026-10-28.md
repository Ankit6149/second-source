## 1. Product invariant
Second Source explores **explicitly authorized** black-box behavior through scoped observations and active model-generated experiments; then reconstructs only the user's required subsystem and scores an independent candidate against a sealed evaluator without exposing reference implementation or withheld tests to candidate generation. This is **not** source recovery, universal cloning, exploit automation, or unauthorized access.

Three independent scopes are mandatory: ObservationScope (can inspect), ImplementationScope (must reconstruct), and ExclusionScope (must avoid). A permitted observation NEVER automatically grants permission to implement a feature.

## 4. Technical contracts to reuse, not recreate
- `src/second_source/contracts.py`: `ScopeContract`, `ProposedAction`, `ProposedFile`, `Observation`, `SequenceResult`. `SideEffect` uses `read_only`, `local_mutation`, `external_mutation`, `sensitive` internally; G2's public planner maps owner-approved `owned_mutation` to local mutation.
- `src/second_source/scope_guard.py`: `validate_action()` and `validate_candidate_files()` are deterministic final authority. Model cannot grant operator approval.
- `src/second_source/reference.py`: `CLIReferenceAdapter.execute_sequence(actions, sequence_id=...)` returns `SequenceResult`. Process starts fresh per sequence; state persists within sequence.
- `src/second_source/verifier.py`: `ReferenceProtocol`, `SealedCase`, `DifferentialVerifier.verify(cases) -> EvaluationReport`, `EvaluationReport.model_feedback()`. The model must NEVER receive case IDs, gold inputs/outputs or reference source.
- `fixtures/owned_ledger/public_contract.json` is safe operator-authored interface metadata; it lists allowed commands and authoritative effect categories without hidden behavioral rules.
- Python >=3.11, project-local Windows venv; `python -m pytest -q`, `python -m second_source.demo`. Windows bootstrap: `scripts/bootstrap-windows.ps1`.
- Real inference **only after** the operator explicitly supplies local credentials and budget; never request, log or commit keys.
